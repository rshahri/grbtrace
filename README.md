# grbtrace 🌌⚡

A Python pipeline for detecting and analyzing Gamma-Ray Bursts (GRBs) using time series data from gamma-ray telescopes like Fermi GBM.

---

## 📚 Overview

**grbtrace** is designed to process raw FITS data from high-energy observatories, extract light curves, identify burst events, and analyze key features such as T90 duration, fluence, and energy distribution.

This tool is meant for researchers, students, and enthusiasts in astrophysics and data science who want to explore GRB data in a reproducible, modular, and scalable way.

---

## 🚀 Features

- 📥 Parse TTE FITS data from Fermi Gamma-ray Space Telescope  
- ⏱️ Generate and visualize binned light curves  
- 🧠 Detect burst events using thresholding or Bayesian Blocks  
- 📊 Extract astrophysical features (e.g., T90, peak flux, hardness ratio)  
- 🖼️ Produce plots for publication or interactive analysis  
- 🔧 Designed for extensibility and future ML-based classification
